¡Reúne cada palo de A a K arriba para ganar! El clásico solitario (Klondike). Apila cartas en orden descendente alternando rojo y negro. Arrastra las cartas para moverlas o tócalas para moverlas automáticamente.

Cómo se juega

  1. Arrastra las cartas para moverlas o tócalas para moverlas a un lugar válido
  2. Siete columnas abajo: apila colores alternos, un valor menos · Solo K en columnas vacías
  3. Cuatro pilas arriba: reúne cada palo de A → K para ganar
  4. Deshacer y pistas ilimitados · Autocompletar cuando todas las cartas estén boca arriba
  5. 👀 Mirar: muestra las cartas boca abajo 3 s (una vez por partida) · ✨ Sube la carta dorada para +100 · Sube cartas seguidas en 3 s para 🔥 racha
