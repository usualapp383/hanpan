¡Dibuja cada línea de un solo trazo sin repasar ninguna! En la última etapa de cada capítulo, dibuja una prenda de hanbok como un jeogori, una falda o zapatos de flores de un solo trazo y la dama se la pondrá. Reúne estrellas para desbloquear nuevos colores de hanbok.

Cómo se juega

  1. Empieza desde un punto y arrastra por las líneas para pintar con el pincel
  2. No puedes repetir la misma línea · Dibuja todas las líneas para ganar
  3. Vuelve atrás para deshacer un paso · ¿Atascado? ↺ Reiniciar
  4. Sin deshacer = 3 estrellas · Usar una pista = 1 estrella
