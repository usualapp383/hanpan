어떤 게임인가요?

빨간 화면이 초록색으로 바뀌는 순간 누르세요! 5번 재서 평균 반응 속도(ms)를 알려 드려요. 친구와 누가 더 빠른지 겨뤄 보세요.

목표 · 초록색이 되는 순간 누르기. 5번 평균 반응 속도가 기록이에요.

게임 방법

  1. 빨간 화면에서 기다려요 · 너무 빨리 누르면 다시
  2. 초록색이 되는 순간 화면을 누르세요 (스페이스도 돼요)
  3. 5번 잰 평균이 내 기록 · 빠를수록 점수가 높아요
  4. 점수 = 100000 ÷ 평균 ms (250ms면 400점)

공략 팁

  • 화면 한가운데를 보고 손가락은 화면 위에 살짝 띄워 두세요
  • 미리 누르면 다시 해야 하니 색이 바뀌는 걸 보고 누르세요
  • 피곤할 땐 느려져요 · 컨디션 측정용으로도 좋아요
  • 온라인 반응 속도 측정은 보통 200~300ms 사이에 많이 나와요
