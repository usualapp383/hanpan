어떤 게임인가요?

↓↘→ + 주먹 같은 커맨드로 필살기! 뒤로 누르면 막기, 콤보를 이어 상대를 하나씩 꺾는 아케이드. 필살 버튼만 눌러도 기술이 나가요.

목표 · 아케이드: 상대 4명(마지막은 그림자 태풍)을 차례로 3판 2선승으로 꺾으면 챔피언. 둘이서 모드는 한 판 승부.

게임 방법

  1. 상대 반대쪽으로 누르고 있으면 막기. 다리 걸기는 앉아서 막고, 점프 공격은 서서 막아야 해요.
  2. 주먹 → 주먹 → 발로 3단 콤보. 맞히는 중에 필살기를 누르면 이어져요(캔슬).
  3. 붙어서 앞+주먹은 잡아 던지기(막아도 소용없음).
  4. 때리고 맞으면 아래 게이지가 차요. 가득 차면 필살 버튼으로 초필살!
  5. 커맨드가 어려우면 필살 버튼만: 방향 없이=첫째 기술, 위=둘째, 뒤=셋째.

등장하는 것들

  • ↓↘→ + 주먹 · 첫째 필살 (장풍 · 기공탄 · 돌진 · 표창)
  • →↓↘ + 주먹 · 둘째 필살 (승천권 · 올려차기 · 몸통 누르기 · 순간이동)
  • ↓↙← + 발 · 셋째 필살 (회오리발 · 번개발 · 메치기 · 급강하)
  • ↓↘→↓↘→ + 주먹 · 초필살 (게이지 가득일 때)
  • 캐릭터 · 태풍 균형 · 번개 빠름 · 바위 힘 · 바람 날쌤
